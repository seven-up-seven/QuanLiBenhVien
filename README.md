# Hotel Management Web Application
## What we used: 
- Displaying information and user interaction: Razor View (.cshtml) 
- Storaging and querying data: C# .Net EntityFrameworkCore + Visual Studio 2022, MS SQL Server + SQL Server Management Studio 20  
This is our first attempt at building a hospital management web/application.
While we’ve put a great deal of effort into this project, we acknowledge that it may still contain mistakes in business logic and is currently lacking in several features.
We view this as a valuable learning experience and are open to feedback for future improvements.
